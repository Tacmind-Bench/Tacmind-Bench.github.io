BENCHMARK STATUS

Benchmark availability

TacMind-Bench includes 128 manipulation tasks: 28 Standard tasks and 100 Extra tasks. Explore recorded demonstrations and evaluation perturbations on this website.

Find dataset releases on Hugging Face and ModelScope.

The benchmark is under active development. Code will be released progressively, with support for more tactile sensors and tasks. Follow the project on GitHub for updates.
